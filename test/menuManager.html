SETTINGS

메뉴 관리

로그인, 결제 정보, 메뉴 구성, 메뉴판 이미지를 한 화면에서 관리하는 운영용 설정 페이지입니다.

관리자 로그인
메뉴 및 결제 설정을 변경하려면 관리자 계정으로 로그인해야 합니다.
관리자 상태
현재 로그인된 관리자 계정과 세션 상태를 표시합니다.
로그인됨
결제 정보 관리
입금 계좌와 자릿세 단가를 저장해 주문 페이지와 테이블 관리에 반영합니다.
긴급 공지 관리
고객 주문 화면 상단에 표시할 운영 공지를 관리합니다.
메뉴 등록 / 수정
메뉴명, 가격, 구분, 옵션, 조합형 설정, 표시 여부를 관리합니다.
옵션이 없으면 추가하지 않아도 됩니다.
메뉴판 이미지
현재 메뉴판 이미지를 확인하고 새 파일로 교체 업로드할 수 있습니다.
등록된 메뉴 목록
정렬 순서, 표시 여부, 매진 여부, 옵션 구성까지 한눈에 확인하고 바로 수정할 수 있습니다.
