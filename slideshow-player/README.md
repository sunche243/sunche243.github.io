# Frameflow

사진과 PDF를 브라우저에 저장하고 전체 화면으로 자동 재생하는 로컬 슬라이드 플레이어입니다.

## 기능

- 이미지 다중 업로드 및 PDF 페이지 자동 변환
- MP4, MOV, WEBM 등 브라우저 지원 영상 재생
- 여러 슬라이드쇼 생성, 전환, 이름 변경과 삭제
- 드래그 또는 버튼으로 순서 변경
- 여러 슬라이드 선택 후 표시 시간·전환 효과 일괄 적용
- 슬라이드 복제와 삭제 후 8초 동안 되돌리기
- 전체 화면 자동 재생, 일시 정지, 이전/다음 이동
- 원하는 슬라이드부터 바로 전체 화면 재생
- 전체 예상 재생 시간 표시
- 재생 중 전체 경과 시간·총 재생 시간과 진행률 표시
- 순서대로 / 랜덤 / 뒤에서부터 재생
- 개별 슬라이드 또는 전체 기본 표시 시간 설정
- 교차 페이드, 검정/흰색 페이드, 슬라이드, 확대 전환을 전체 또는 슬라이드별 지정
- 슬라이드별 전환 효과와 전환 시간 조절
- 여러 MP3, M4A, WAV 배경 음악을 순서대로 무한 반복 재생
- 음악 미리 듣기, 순서 변경, 볼륨 조절과 삭제
- 음악 시작·종료 페이드 시간 조절
- 영상 자체 음량과 배경 음악 재생 중 영상 음소거 설정
- 슬라이드쇼 일시정지·재개·종료와 배경 음악 동기화
- 방향키로 이전·다음 이동, 스페이스바로 재생·정지
- `?` 단축키 안내와 Home/End 처음·마지막 이동
- 재생 중 화면 자동 꺼짐 방지
- 재생 중 조작이 없으면 컨트롤과 마우스 커서 자동 숨김
- 브라우저 IndexedDB에 파일 자동 저장
- 탭을 닫거나 새로고침한 뒤 재접속해도 사진·PDF·음악 자동 복원
- 실제 저장공간 사용량 표시와 용량 부족 사전 경고
- 표시하거나 재생할 수 없는 사진·영상·음악 경고
- 현재 슬라이드쇼 전체를 `.frameflow` 파일로 백업하고 새 슬라이드쇼로 복원

## 실행

```bash
npm install
npm run dev
```

빌드 검증은 `npm run build`, 테스트는 `npm test`, 정적 검사는 `npm run lint`로 실행합니다.

> 업로드한 파일은 외부 서버로 전송되지 않습니다. 큰 파일은 `localStorage`가 아닌 브라우저의 대용량 로컬 저장소인 IndexedDB에 보관됩니다. 현재 브라우저의 사이트 데이터를 삭제하면 함께 제거됩니다.
